Snake – Java OOP Edition

Eine objektorientierte Implementierung des Klassikers Snake in Java (Swing/AWT), entwickelt zur Vertiefung von Software-Architektur, Event-Handling und Algorithmen der Spieleentwicklung.

 Features

Klassische Spielmechanik: Snake-Steuerung über Tastatur, Futter-Spawning und Highscore-Tracking.

Saubere Objektorientierung (OOP): Klare Trennung von Spielobjekten (Snake, Food, Board/Game Engine).

Collision Handling: Präzise Abfrage von Wand- und Eigenkollisionen.

Game-Loop & Grid-Rendering: Flüssiges Rendering der Spielwelt über Timer-Intervalle.

 Software-Architektur & UML

Das Projekt wurde vor der Entwicklung objektorientiert modelliert, um eine saubere Vererbung und Kapselung der Spiel-Klassen zu gewährleisten.

(Falls ein Bild deines UML-Diagramms im Ordner liegt, wird es hier angezeigt:)


Tech Stack & Konzepte

Sprache: Java (JDK 8+)

GUI-Framework: Java Swing / AWT

Paradigmen: Objektorientierte Programmierung (OOP), Event-Driven Programming (KeyListener), Timer-basiertes Loop-System

 Projekt ausführen

Repository klonen:

git clone https://github.com/squallyjam/Snake-oop-easy.git


In das Projektverzeichnis wechseln:

cd Snake-oop-easy


Kompilieren und Starten (über Konsole):

javac src/*.java -d bin
java -cp bin Main


(Oder das Projekt direkt in IntelliJ / VS Code / Eclipse öffnen und die Main.java ausführen).

 Hintergrund

Entwickelt zur praktischen Anwendung von objektorientierten Konzepten (Kapselung, Vererbung, Polymorphie) und Datenstrukturen im Rahmen der eigenen Softwareentwicklung.
